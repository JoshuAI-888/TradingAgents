# Loss-aware download values

This local change aligns server screener CSV/SpreadsheetML, client screener CSV/SpreadsheetML and shortlist CSV numeric validity with the typed display contract. Numeric strings, Boolean factors and nonfinite numbers cannot become ordinary numeric factor cells. Missing factors are explicitly Unavailable; invalid nonnull factors additionally carry `export_value_issues`. Valid zero and negative numbers remain numbers, including Excel Number cells. Flags retain known Boolean/0/1 semantics.

Nested nonfinite source evidence is retained as an explicit `export_unavailable: nonfinite_number` object with its source representation rather than silently becoming null. Original rows are not mutated. CSV text beginning with whitespace plus a formula operator, or tab/newline/carriage return, receives the existing formula protection consistently across screen, comparison and shortlist exports. SpreadsheetML control characters forbidden by XML 1.0 are represented as literal Unicode escape text. Canonical row order and scope remain unchanged; shortlist missing quote prices retain blank cells and their existing Quote unavailable label.

Validation: 448 API/worker tests and 122 JavaScript tests pass. New actual API response tests parse CSV and SpreadsheetML, reconcile ordered canonical IDs, confirm unavailable String cells versus valid zero Number cells, preserve structured NaN evidence and XML control text. JavaScript tests execute the real download serializer into Blob objects and check matching order, row numbers, diagnostics, typed Excel values, shortlist formula protection and source immutability. These are automated response/serializer checks, not a fresh interactive-browser download or live-provider qualification.

R11 remains open for production downloads, every remaining scope, pair-review revisions, interruption recovery and real account transitions. No release, investment-grade source qualification, or full gate closure is claimed.
